Ostree Native Containers + ROS2

Oct 10, 2023

ros2-fcos-gpio


During my 16 month internship and working with rpm-ostree, I learned about ostree native containers. Ostree native containers allow you to boot and upgrade your OS from a container image. In other words, the container image is not run as a container, but it changes the host system itself. My team (CoreOS) had something called hack days, in which every friday we are able to spend the day learning something new. Since my background is in robotics engineering, I capitalized on this opportunity to integrate ostree native containers in a robotics context. Robot Operating System or ROS is an open-source set of software libraries and tools that help you build robot applications. Configuring ROS from source usually takes upwards of half an hour or longer. Therefore, the idea is to layer ROS on top of an image based OS, rebase your system, and run ROS immediately after rebooting. In addition, you can also install and configure the necessary drivers to access GPUs, GPIO ports, or other hardware interfaces within the base image. I have tested this and can get ROS running and interfacing with hardware within 5 minutes.
